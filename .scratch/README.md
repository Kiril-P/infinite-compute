# Local issue tracker

Specifications and tickets live here. Follow [issue-tracker conventions](../docs/agents/issue-tracker.md) and [triage roles](../docs/agents/triage-labels.md).

- [V1 specification](v1/spec.md): seven ordered implementation tickets for Chapter I.
- [Full-game planning specification](full-game/spec.md): campaign scope and validation gates beyond v1; later implementation tickets are created one slice at a time.

Current authorization covers implementation and verification of Phase 0 / ticket 01 only, superseding the planning-only pause. Stop at its verified completion. A ready-for-agent label describes sufficient ticket context, not authorization for later tickets. Read [continuity](../docs/CONTINUITY.md) first.

For every build or continuation, follow [the build loop](../docs/agents/build-loop.md). Check `Execution` and acceptance evidence to determine progress; use the latest ticket checkpoint and continuity to resume.
